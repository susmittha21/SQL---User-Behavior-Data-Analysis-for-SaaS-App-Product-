# SQL-User-Behavior-Data-Analysis-for-SaaS/App-Product

## OBJECTIVE 
This project analyzes user behavior data from a sample SaaS / app product using MySQL.
The goal is to understand how users interact with the product after signup and identify key business insights and how sql works.

## TOOLS USED 
MySQL Workbench
SQL

## DATASET DESCRIPTION
users table:
user_id – Unique user identifier
signup_date – Date user signed up
source – Acquisition source (ads, organic, referral)

events table:
user_id – User identifier
event_date – Date of event
event_type – User action (signup, login, add_to_cart, purchase)
